# Parenting OS · 育儿操作系统

A scientific operating system for parenting, child development, and family growth. Bilingual (EN / 中文) with eight modules: Child Development Atlas, Parenting Knowledge System, Emotion & Communication Engine, Learning & Education System, Health & Habit Tracker, Parenting Decision Simulator, Family Relationship Layer, and an AI Parenting Coach.

## Links

- **Live:** [parenting-os.psyverse.fun](https://parenting-os.psyverse.fun)
- **Vercel:** https://parenting-os.vercel.app
- **GitHub:** https://github.com/gewenbo888/parenting-os

## Stack

Plain HTML, CSS, vanilla JavaScript. No build step. Bilingual via `[data-lang]` + CSS attribute selectors. Fonts from Google Fonts (Fraunces + IBM Plex). SVG-only diagrams.
